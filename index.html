Stammdatenblatt und Wünsche

Ihre Angaben werden nur auf diesem Gerät gespeichert und nicht an uns übertragen. Sie entscheiden am Ende selbst, wie Sie uns die Daten geben.

Löscht Ihre bisherigen Eingaben aus dem Zwischenspeicher dieses Geräts. Wichtig, wenn Sie ein geteiltes oder öffentliches Gerät benutzen.

Abschnitt 1 von 8

    Fast geschafft — Ihre Angaben herunterladen

    Klicken Sie auf die Knöpfe, um Ihre Angaben zu speichern. Beides bleibt auf Ihrem Gerät — es wird nichts an uns geschickt.

    Erstellt ein PDF mit Ihren Angaben. Das können Sie ausdrucken oder zum Gespräch mitbringen.
    Eine Datei für unsere Mitarbeitenden, damit sie Ihre Angaben nicht abtippen müssen. Für Sie selbst ist das PDF das Wichtigere.

    So geht es weiter

    Sie können uns Ihre Angaben auf mehreren Wegen geben — Sie entscheiden:

    • Das PDF ausdrucken und zum Beratungsgespräch mitbringen.
    • Das PDF per Post an uns schicken.
    • Das PDF per E-Mail an info@sozialhummel.de schicken. Hinweis: E-Mail ist kein sicherer Weg. Sie entscheiden selbst, ob Sie ihn nutzen möchten.
    • Telefonisch einen Termin vereinbaren und die Angaben im Gespräch besprechen.

    Tipp: Wenn Sie ein geteiltes oder öffentliches Gerät benutzen, löschen Sie jetzt den Zwischenspeicher.

    Datenschutzhinweis Entwurf

    Dieser Text ist ein Entwurf. Die Sozialhummel gGmbH lässt ihn noch rechtlich prüfen.

    • Das Formular überträgt keine Daten. Alle Eingaben bleiben in Ihrem Browser auf diesem Gerät.
    • Zwischenspeicher. Damit Sie nicht von vorn anfangen müssen, wird Ihr Stand auf diesem Gerät gespeichert (im sogenannten „localStorage" des Browsers). Sie können ihn jederzeit mit dem Knopf „Alle Daten von diesem Gerät löschen" entfernen.
    • PDF und JSON. Am Ende erzeugt das Formular auf Ihrem Gerät ein PDF und eine JSON-Datei. Was Sie damit machen, entscheiden Sie selbst.
    • Keine Einwilligung nötig. Weil wir keine Daten verarbeiten, gibt es hier keine Einwilligungserklärung.
